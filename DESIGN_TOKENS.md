# Система дизайн-токенов (Layout System Tokens)

В проекте реализована консистентная адаптивная система отступов и размеров, основанная на CSS-переменных (токенах). Все токены объявлены глобально в `src/app.css` внутри псевдо-класса `:root`.

На мобильных экранах (`max-width: 600px`) базовые токены автоматически переопределяются (сужаются), благодаря чему все компоненты адаптируются без дополнительных медиазапросов внутри самих компонентов.

## 1. Контейнерные отступы (Layout Paddings)

Определяют пространство между контентом и границами контейнера.

* **Горизонтальные (X-axis):**
  * `--layout-px-base` (`32px` -> `20px`) — Главные контейнеры (например, карточки `Block`).
  * `--layout-px-sm` (`24px` -> `20px`) — Вложенные контейнеры (например, карточки `SubBlock`).

* **Вертикальные (Y-axis):**
  * `--layout-py-base` (`32px` -> `20px`) — Отступы контента сверху/снизу внутри главных контейнеров.
  * `--layout-py-sm` (`24px` -> `20px`) — Отступы контента сверху/снизу во вложенных контейнерах.

## 2. Заголовки (Title Paddings)

Контролируют внутреннюю высоту плашек заголовков. Горизонтальный отступ заголовки наследуют от своего контейнера (`--layout-px-base` или `--layout-px-sm`).

* `--title-py-lg` (`18px`) — Крупный заголовок верхнего уровня (внутри `Block`).
* `--title-py-md` (`16px`) — Средний заголовок (внутри `SubBlock`).
* `--title-py-sm` (`12px`) — Малый заголовок-разделитель (внутри `Section`).

## 3. Расстояния между элементами (Gaps)

Определяют отступы (gap) для flex и grid контейнеров. Заменяют использование `margin`.

* `--gap-layout` (`32px` -> `24px`) — Расстояние между независимыми блоками (Block 1 -> Block 2) на главной странице.
* `--gap-section` (`24px` -> `16px`) — Расстояние между секциями/под-блоками внутри одного главного блока.
* `--gap-fields` (`16px` -> `12px`) — Расстояние между инпутами и атомарными элементами форм.
* `--gap-sm` (`8px` -> `6px`) — Микро-отступы (например, между иконкой и текстом внутри кнопки).
* `--gap-xs` (`4px`) — Мельчайшие отступы (например, между радио-кнопками в плотной группе).

## 4. Внутренние отступы компонентов (Element Paddings)

Применяются непосредственно к атомарным элементам (инпуты, текстовые области, дропдауны) для их внутреннего отступа от рамки до текста/иконок.

* `--element-px` (`16px` -> `12px`) — Горизонтальные внутренние отступы по бокам в `TextInput`, `SelectInput`, `PhoneInput`, `TextArea`, а также позиционирование крестика очистки.
* `--element-py` (`16px` -> `12px`) — Вертикальные внутренние отступы (сверху/снизу) в многострочных элементах, таких как `TextArea` и карточки внутри `SelectionGrid`.

## 5. Типографика (Typography Scale)

### Размеры шрифта (Font Sizes)
* `--text-xs` (`0.75rem` / 12px) — мелкие подписи, тултипы
* `--text-sm` (`0.85rem` / ~14px) — вторичный текст, мелкие кнопки
* `--text-base` (`1rem` / 16px) — основной текст по умолчанию
* `--text-lg` (`1.1rem` / ~18px) — увеличенный текст, подзаголовки
* `--text-xl` (`1.25rem` / 20px) — заголовки блоков
* `--text-2xl` (`1.5rem` / 24px) — крупные заголовки
* `--text-3xl` (`1.875rem` / 30px) — иконки в кнопках и хинтах
* `--text-4xl` (`2.25rem` / 36px) — огромные заголовки
* `--text-hero` (`5rem` / 80px) — для главного экрана (Intro/Outro)

### Насыщенность (Font Weights)
* `--font-weight-normal: 400;`
* `--font-weight-medium: 500;`
* `--font-weight-semibold: 600;`
* `--font-weight-bold: 700;`
* `--font-weight-extrabold: 800;`

### Межстрочный интервал (Line Heights)
* `--line-height-none: 1;`
* `--line-height-tight: 1.2;`
* `--line-height-normal: 1.4;`
* `--line-height-relaxed: 1.6;`

## 6. Системные переменные (System Variables)

* `--scrollbar-width` (`10px`) — Зафиксированная ширина скроллбара. Используется в функции `calc()` (например, в `App.svelte`) для резервирования места под скролл и предотвращения скачков интерфейса (layout shift) при переходе между шагами.
