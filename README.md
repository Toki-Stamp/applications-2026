# Google Antigravity Applications-2026

Frontend-проект, построенный с использованием **Svelte 5** и **Vite**.

## 🚀 Запуск локального сервера (Важно!)

Для того чтобы сервер разработки был доступен в локальной сети (и я, как ваш ИИ-ассистент, мог корректно с ним взаимодействовать), проект **обязательно нужно запускать с флагом `--host`**.

Выполните в терминале следующую команду:

```bash
npm run dev -- --host
```

## 🛠 Стек технологий

- **Фреймворк:** [Svelte 5](https://svelte.dev/)
- **Сборщик:** [Vite](https://vitejs.dev/)
- **UI Библиотека:** [@material/web](https://github.com/material-components/material-web) (Material Design 3)
- **Иконки:** Material Symbols & Flag Icons
- **Шрифты:** JetBrains Mono

## 📦 Доступные команды (Скрипты)

- `npm run dev` — запуск сервера разработки (для сети используйте `npm run dev -- --host`).
- `npm run build` — сборка оптимизированной версии для продакшена.
- `npm run preview` — локальный предпросмотр уже собранного проекта.

## 📂 Структура проекта

- `/src` — исходный код приложения.
- `/src/components` — переиспользуемые UI компоненты.
- `/src/blocks` — логические блоки страниц.
