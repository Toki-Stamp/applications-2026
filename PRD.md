# Идея: Форма заявки на участие в ежегодном мероприятии

## Концепция
Веб-форма для сбора заявок от участников. Данные из формы должны автоматически сохраняться в Google Таблицу для удобного просмотра и аналитики.

**Контекст мероприятия:**
Ежегодная "сходка" компании единомышленников со всех уголков страны. Мероприятие традиционно проходит на территории туристической базы "Лесное Озеро" (Брестская область, Барановичский район, п/о Подгорное), где участники собираются на все выходные.

## Структура формы (Логика)
Форма будет разделена на 5 смысловых блоков. 

### Блок 1: Формат участия (Тип заявки)
- Тип заявки: (Опции: Индивидуальная / Групповая) (Обязательно)
- *Если "Групповая":* Укажите количество дополнительных участников (Число)
- *Если "Групповая":* Условия для дополнительных участников:
    - **Единые условия** (трансфер, проживание и меню полностью совпадают с вашими)
    - **Дифференцированные условия** (возможность указать индивидуальные предпочтения для каждого гостя)

### Блок 2: Персональные данные

#### 2.1. Основной участник (Заявитель)
- Никнейм (Обязательно)
- Имя (Опционально)
- Фамилия (Опционально)
- Номер телефона (Обязательно)

#### 2.2. Дополнительные участники (Гости)
*Заполняется, только если в Блоке 1 выбрана «Групповая» заявка. Поля дублируются для каждого гостя.*
- Имя (Обязательно, по умолчанию предзаполняется как "[Никнейм заявителя] +1", "[Никнейм заявителя] +2" и т.д.)
- Никнейм (Опционально)
- Фамилия (Опционально)
- Номер телефона (Опционально)

### Блок 3: Транспортировка
*Заполняется один раз на всю заявку (подразумевается, что группа добирается вместе). Если участники группы едут раздельно, им необходимо заполнить отдельные индивидуальные заявки.*
- Город отправления (Обязательно)

#### 3.1. Дорога ТУДА (на базу)
- Способ прибытия: (Опции: Как водитель / Ищу место в авто / На организованной маршрутке / Самостоятельно) (Обязательно)
- *Если "Как водитель":* Количество свободных мест в авто (для других участников, помимо вашей группы) (Число)
- День отправления на базу: (Опции: Пятница / Суббота / Воскресенье) (Обязательно)
- Ориентировочное время отправления: (Поле выбора времени, ЧЧ:ММ) (Обязательно)

#### 3.2. Дорога ОБРАТНО (с базы)
- Способ отъезда: (Опции: Тот же, что и туда / Как водитель / Ищу место в авто / На организованной маршрутке / Самостоятельно) (Обязательно)
- *Если "Как водитель":* Количество свободных мест в авто (для других участников) (Число)
- День отъезда с базы: (Опции: Пятница / Суббота / Воскресенье) (Обязательно)
- Ориентировочное время отъезда: (Поле выбора времени, ЧЧ:ММ) (Обязательно)

#### 3.3. Дополнительно по транспорту
- Комментарий к дороге (Опционально) *(Например: "Могу забрать людей с вокзала", "Укачивает сзади", "Есть пустой багажник для общих вещей")*

### Блок 4: Обеспечение
*Если в Блоке 1 выбраны "Единые условия", заполняется один раз на всех. Если "Дифференцированные" — вопросы дублируются для каждого гостя.*

#### 4.1. Продукты питания
*Укажите потребность для расчета продуктового взноса.*
- Потребность в питании: (Опции: Без питания (по умолчанию) / Требуется питание) (Обязательно)
- *Если "Требуется питание", отметьте нужные периоды: (Чекбоксы)*
    - Пятница: Утро (до обеда)
    - Пятница: Вечер (после обеда)
    - Суббота: Утро (до обеда)
    - Суббота: Вечер (после обеда)
    - Воскресенье: Утро (до обеда)

#### 4.2. Алкогольные напитки
*Укажите потребность для расчета алкогольного взноса.*
- Потребность в алкоголе: (Опции: Не пью (по умолчанию) / Буду пить) (Обязательно)
- *Если "Буду пить", отметьте нужные периоды: (Чекбоксы)*
    - Пятница: Утро (до обеда)
    - Пятница: Вечер (после обеда)
    - Суббота: Утро (до обеда)
    - Суббота: Вечер (после обеда)
    - Воскресенье: Утро (до обеда)

### Блок 5: Проживание
*Заполняется один раз на всю заявку.*
- Потребность в проживании: (Опции: Размещаюсь самостоятельно (по умолчанию) / Требуется забронировать номер на базе) (Обязательно)
- *Если "Требуется забронировать номер на базе":*
    - Укажите ночевки: (Чекбоксы, можно выбрать несколько)
        - Ночь с пятницы на субботу
        - Ночь с субботы на воскресенье
    - Дополнительные пожелания к номеру и соседям (Опционально) *(Например: "Нужна двуспальная кровать", "Поселите рядом с Shadow", "Хочу индусов в соседи")*

### Блок 6: Свободный микрофон
*Для любой другой информации, которая не вошла в предыдущие блоки.*
- Комментарий или пожелания организаторам (Опционально, многострочный текст) *(Например: "Привезу с собой гитару", "Могу помочь с мангалом" и т.д.)*

### Экран после отправки заявки
*Текст, который увидит пользователь после успешной отправки формы.*
> "Ваша заявка принята! 🎉 Организаторы обработают данные, рассчитают итоговую сумму (оргвзнос + проживание + питание + проезд) и свяжутся с вами по указанному контакту для подтверждения."

**Примечание по визуалу и файлам:**

- Прикрепление файлов (фото/pdf) на данном этапе не требуется.
