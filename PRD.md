# Идея: Форма заявки на участие в ежегодном мероприятии

## Концепция

Веб-форма для сбора заявок от участников. Данные из формы должны автоматически сохраняться в Google Таблицу для удобного просмотра и аналитики.

**Контекст мероприятия:**
Ежегодная "сходка" компании единомышленников со всех уголков страны. Мероприятие традиционно проходит на территории туристической базы "Лесное Озеро" (Брестская область, Барановичский район, п/о Подгорное), где участники собираются на все выходные.

## Структура формы (Логика)

Форма будет разделена на 5 смысловых блоков.

### Блок 1: Формат участия (Тип заявки)

- Тип заявки: (Опции: Индивидуальная / Групповая) (Обязательно)
- _Если "Групповая":_ Укажите количество дополнительных участников (Число)
- _Если "Групповая":_ Условия для дополнительных участников:
  - **Единые условия** (трансфер, проживание и меню полностью совпадают с вашими)
  - **Дифференцированные условия** (возможность указать индивидуальные предпочтения для каждого гостя)

### Блок 2: Персональные данные

#### 2.1. Основной участник (Заявитель)

- Никнейм (Обязательно)
- Имя (Опционально)
- Фамилия (Опционально)
- Номер телефона (Обязательно)

#### 2.2. Дополнительные участники (Гости)

_Заполняется, только если в Блоке 1 выбрана «Групповая» заявка. Поля дублируются для каждого гостя._

- Имя (Обязательно)
- Никнейм (Опционально)
- Фамилия (Опционально)
- Номер телефона (Опционально)

### Блок 3: Транспортировка

_Заполняется один раз на всю заявку (подразумевается, что группа добирается вместе). Если участники группы едут раздельно, им необходимо заполнить отдельные индивидуальные заявки._

#### 3.1. Дорога ТУДА (на базу)

- Способ прибытия: (Опции: Как водитель / Ищу место в авто / На организованной маршрутке / Самостоятельно) (Обязательно)
- _Если "Как водитель":_ Количество свободных мест в авто (для других участников, помимо вашей группы) (Число)
- День отправления на базу: (Опции: Пятница / Суббота / Воскресенье) (Обязательно)
- Ориентировочное время отправления: (Поле выбора времени, ЧЧ:ММ) (Обязательно)
- Город отправления (текстовое поле, обязательно)

#### 3.2. Дорога ОБРАТНО (с базы)

- Способ отъезда: (Опции: Как водитель / Ищу место в авто / На организованной маршрутке / Самостоятельно) (Обязательно)
- День отъезда с базы: (Опции: Пятница / Суббота / Воскресенье) (Обязательно)
- Ориентировочное время отъезда: (Поле выбора времени, ЧЧ:ММ) (Обязательно)

#### 3.3. Дополнительно по транспорту

- Комментарий к дороге (Опционально) _(Например: "Могу забрать людей с вокзала", "Укачивает сзади", "Есть пустой багажник для общих вещей")_

### Блок 4: Обеспечение

_Если в Блоке 1 выбраны "Единые условия", заполняется один раз на всех. Если "Дифференцированные" — вопросы дублируются для каждого гостя._

#### 4.1. Продукты питания

_Укажите потребность для расчета продуктового взноса._

- Потребность в питании: (Опции: Без питания (по умолчанию) / Требуется питание) (Обязательно)
- _Если "Требуется питание", отметьте нужные периоды: (Чекбоксы)_
  - Пятница: Утро (до обеда)
  - Пятница: Вечер (после обеда)
  - Суббота: Утро (до обеда)
  - Суббота: Вечер (после обеда)
  - Воскресенье: Утро (до обеда)

#### 4.2. Алкогольные напитки

_Укажите потребность для расчета алкогольного взноса._

- Потребность в алкоголе: (Опции: Не пью (по умолчанию) / Буду пить) (Обязательно)
- _Если "Буду пить", отметьте нужные периоды: (Чекбоксы)_
  - Пятница: Утро (до обеда)
  - Пятница: Вечер (после обеда)
  - Суббота: Утро (до обеда)
  - Суббота: Вечер (после обеда)
  - Воскресенье: Утро (до обеда)

### Блок 5: Проживание

_Для групповых заявок с едиными условиями заполняется один раз на всех. Для заявок с дифференцированными условиями заполняется индивидуально для каждого участника (заявителя и гостей)._

- Потребность в проживании: (Опции: Требуется забронировать номер на базе / Размещаюсь самостоятельно) (Обязательно)
- _Если "Требуется забронировать", укажите ночевки: (Чекбоксы)_
  - С пятницы на субботу
  - С субботы на воскресенье
- Дополнительные комментарии к проживанию и обеспечению (Опционально) _(Например: "Нужна двуспальная кровать", "Поселите рядом с Shadow", "Хочу индусов в соседи")_

### Блок 6: Свободный микрофон

_Для любой другой информации, которая не вошла в предыдущие блоки._

- Комментарий или пожелания организаторам (Опционально, многострочный текст) _(Например: "Привезу с собой гитару", "Могу помочь с мангалом" и т.д.)_

### Экран после отправки заявки

_Текст, который увидит пользователь после успешной отправки формы._

> "Ваша заявка принята! 🎉 Организаторы обработают данные, рассчитают итоговую сумму (оргвзнос + проживание + питание + проезд) и свяжутся с вами по указанному контакту для подтверждения."

**Примечание по визуалу и файлам:**

- Дизайн и цвета пока не рассматриваем, фокусируемся строго на логике.
- Прикрепление файлов (фото/pdf) на данном этапе не требуется.
