# Запуск формы в интернете (Деплой)

Теперь, когда наша форма готова и Google Таблица настроена на прием заявок, осталось сделать так, чтобы форма была доступна по ссылке для всех желающих.

Поскольку наше приложение — это современный статический сайт (созданный на Svelte + Vite), его можно опубликовать (задеплоить) **абсолютно бесплатно**.

Ниже представлены два способа. Выберите тот, который вам больше нравится!

---

## Способ 1: Самый быстрый (Netlify Drop)

_Подходит, если вы хотите опубликовать сайт прямо сейчас за 1 минуту, без сложной настройки._

### Шаг 1: Сборка проекта

Для начала нам нужно сгенерировать файлы, оптимизированные для интернета (Production build).

1. Откройте терминал (командную строку) в папке с вашим проектом.
2. Введите команду:
   ```bash
   npm run build
   ```
3. После завершения команды в папке проекта появится новая папка **`dist`**. Это и есть готовый к публикации сайт!

### Шаг 2: Публикация

1. Откройте в браузере сайт [Netlify Drop](https://app.netlify.com/drop).
2. Зарегистрируйтесь или войдите с помощью Google/GitHub (это бесплатно).
3. После входа вас попросят перетащить (drag and drop) папку с сайтом.
4. Перетащите папку **`dist`** прямо в окно браузера.
5. Подождите несколько секунд. Netlify загрузит файлы и выдаст вам ссылку на ваш сайт!
   _(Например: `https://cool-unicorn-12345.netlify.app`)_

> [!TIP]
> **Как поменять ссылку?**
> Выданная ссылка выглядит как случайный набор слов. Вы можете зайти в настройки сайта на Netlify (Site settings -> Change site name) и изменить название на что-то понятное, например `https://zayavka-2026.netlify.app`.

> [!WARNING]
> При таком способе, если вы позже измените что-то в коде (например, добавите новое поле в форму), вам придется заново делать `npm run build` и перетаскивать папку `dist` на Netlify (кнопка "Deploys" -> перетащить папку вниз экрана).

## Способ 2: Профессиональный с автообновлением (Vercel + GitHub)

_Подходит, если вы хотите, чтобы сайт обновлялся автоматически каждый раз, когда мы вносим изменения в код (рекомендуемый вариант)._

### Шаг 1: Публикация кода на GitHub

1. Зарегистрируйтесь на [GitHub](https://github.com/), если у вас еще нет аккаунта.
2. Создайте новый репозиторий: нажмите кнопку **"New"** (или плюсик в правом верхнем углу).
3. Дайте репозиторию имя (например, `application-form-2026`) и нажмите **Create repository**.
4. В терминале вашего проекта (где лежит код) введите команды, чтобы связать папку с GitHub (замените ссылку на свою):
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/application-form-2026.git
   git branch -M master
   git push -u origin master
   ```

### Шаг 2: Подключение Vercel

Vercel — это один из лучших сервисов для хостинга современных сайтов.

1. Откройте [Vercel](https://vercel.com/) и зарегистрируйтесь, выбрав "Continue with GitHub".
2. После входа нажмите кнопку **"Add New..."** -> **"Project"**.
3. В списке вы увидите ваш репозиторий `application-form-2026`. Нажмите кнопку **Import** рядом с ним.
4. Откроется окно настроек. Vercel сам поймет, что это Vite+Svelte проект (в поле _Framework Preset_ будет написано _Vite_).
5. Ничего менять не нужно, просто нажмите большую кнопку **Deploy**.
6. Подождите около минуты, пока идет сборка, и вы увидите конфетти 🎉!

> [!TIP]
> **В чем магия Vercel?**
> Теперь каждый раз, когда мы с вами будем менять код и сохранять его в GitHub, Vercel будет _автоматически_ собирать новую версию сайта и обновлять её в интернете за считанные секунды!

### Шаг 3: Настройка домена (по желанию)

Vercel выдаст вам ссылку вида `https://application-form-2026.vercel.app`. Если она вам не нравится:

1. Зайдите в дашборд проекта на Vercel.
2. Перейдите во вкладку **Settings** -> **Domains**.
3. Нажмите **Edit** рядом с доменом и впишите красивое имя (например, `zayavka-2026.vercel.app`).
4. Если у вас есть собственный купленный домен (например, `myparty.com`), вы также можете подключить его здесь бесплатно.

### Шаг 4: Обновление сайта (Последующие релизы)

Так как мы настроили интеграцию с GitHub, для того чтобы ваши новые изменения появились на сайте, вам нужно просто отправить обновленный код на GitHub.

1. Убедитесь, что вы сохранили все файлы.
2. В терминале введите команды:
   ```bash
   git add .
   git commit -m "Обновление проекта: добавили новую функцию"
   git push origin master
   ```
3. Как только код улетит на GitHub, Vercel **автоматически** подхватит эти изменения и начнёт новую сборку. Подождите 1-2 минуты, обновите страницу в браузере — и ваш сайт будет обновлен!

Попробуйте заполнить заявку с телефона или компьютера и нажмите "Отправить". Если в вашей Google Таблице появилась новая строка — **поздравляю, ваш проект запущен в продакшен!** 🚀
