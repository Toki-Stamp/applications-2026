# Expense Ledger (Управление расходами)

Создание полноценного модуля для внесения и управления расходами в рамках панели администратора.

## Goal

Спроектировать и реализовать премиальный, удобный для мобильных устройств интерфейс добавления расходов, состоящий из формы ввода и ленты добавленных трат. Этот модуль закроет пункт 2.3 из нашего ADMIN_PRD.

## User Review Required

> [!IMPORTANT]  
> **Дизайн селектора категорий:** Вместо стандартного скучного выпадающего списка `<select>`, я предлагаю использовать **Segmented Control** (переключатель в виде кнопок-капсул) для выбора категории (Питание / Алкоголь / Орг). Это быстрее нажимать с телефона и выглядит гораздо дороже. Согласны?

## Proposed Changes

### `src/store.admin.svelte.js`
- Добавление массива `expenses` в хранилище.
- Реализация методов `addExpense(expense)` и `removeExpense(id)`.

### [NEW] `src/components/admin/ExpenseForm.svelte`
- Форма ввода нового расхода.
- Поля: Название (текст), Сумма (число), Категория (Сегментированный переключатель).
- Дизайн инпутов: в стиле нашего glassmorphism с неоновыми подсветками при фокусе.

### [NEW] `src/components/admin/ExpenseList.svelte`
- Лента (список) уже внесенных расходов.
- Каждая запись — стеклянная карточка с цветовым маркером категории (например: зеленый — еда, фиолетовый — алкоголь) и кнопкой удаления.

### `src/components/admin/AdminApp.svelte`
- Интеграция формы и списка в новую секцию «Управление расходами».
