# Локализация приложения (Словарь)

Вся текстовая информация и интерфейсные строки вынесены в файл `ru.js` в текущей директории. Это позволяет легко менять тексты без необходимости править исходный код компонентов, а также закладывает архитектуру для возможного добавления других языков (например, `en.js`, `be.js`).

## Структура объекта `dict`

Объект словаря разбит на несколько логических секций, чтобы было проще найти нужный текст.

### 1. `options`
В этом разделе хранятся варианты выбора для различных элементов управления: выпадающих списков (селектов), радиокнопок и чекбоксов (например, для компонента `SelectionGrid`).
- Если значение опции простое, оно хранится как строка.
- Если опции используются в массиве или объекте, ключи соответствуют константам из `constants.js`.

### 2. `errors`
Здесь хранятся тексты ошибок валидации (например, когда пользователь не заполнил обязательное поле). 
- **Функции генерации строк:** Некоторые ошибки зависят от контекста (например, подставить имя поля, которое не заполнено). В таких случаях используются функции, принимающие аргументы и возвращающие строку (или массив объектов для компонента `RichText`).

### 3. `common`
Глобальные и общие строки, которые используются по всему приложению. В основном это тексты кнопок ("Отмена", "Продолжить", "Далее", "Отправить заявку") и универсальные сообщения.

### 4. `modals`
Тексты для всплывающих окон (модалок). Например:
- Окно очистки формы (`clear`)
- Окно ошибки при отправке (`submitError`)
- Окно восстановления черновика (`draft`)

### 5. `layout`
Тексты элементов каркаса приложения: шапки (`header`) и подвала (`footer`).

### 6. `steps`
Самый объемный раздел. Он разделен на подразделы, каждый из которых соответствует конкретному шагу (экрану) формы:
- `intro`: Вводная страница
- `applicationType`: Формат участия (индивидуальная/групповая)
- `personalData`: Личные данные (ФИО, телефон)
- `transportation`: Логистика (Дорога туда/обратно)
- `provisions`: Обеспечение (Еда, алкоголь)
- `accommodation`: Проживание (Ночевки)
- `freeMic`: Свободный микрофон (Комментарии)
- `outro`: Финальный экран после успешной отправки

Внутри каждого шага хранятся:
- `title` — заголовок шага.
- `...Label` — подписи к полям ввода (например, `firstNameLabel`).
- `...Placeholder` — текст-подсказка внутри поля до начала ввода.
- `...Hint` или `...Helper` — вспомогательный текст или примеры (текст под инпутом).

## Как форматировать текст (RichText)

Приложение поддерживает продвинутое форматирование текстов (например, в подсказках или приветственном тексте) без использования сырого HTML. Это сделано для безопасности и изоляции стилей.

Если тексту нужны акценты, жирный шрифт или капс, вместо обычной строки используется **массив объектов**. Компонент `<RichText />` автоматически распарсит его в красивые `<span>` с нужными CSS-классами.

**Пример:**
```javascript
hint1: [
  { text: "Дорогие друзья, нас ждёт " },
  { text: "юбилейная", highlight: true, upper: true },
  { text: " сходка!" }
]
```

Доступные свойства для объекта внутри массива:
- `text` (String): сам текст фрагмента.
- `highlight` (Boolean): если `true`, текст выделяется акцентным цветом темы.
- `upper` (Boolean): если `true`, текст будет переведен в верхний регистр (КАПС).
- `bold` (Boolean): если `true`, текст будет жирным.

## Динамические тексты (Функции)

Иногда текст должен собираться динамически (например, обращение по имени или нумерация подшагов). В этом случае в словаре создается стрелочная функция:

```javascript
// В ru.js:
forGuest: (name) => `Для ${name}`

// Использование в компоненте Svelte:
dict.steps.accommodation.forGuest(guest.firstName || "Гостя")
```

Такой подход гарантирует, что компоненты остаются "глупыми" (отвечают только за отображение) и не занимаются конкатенацией строк.
